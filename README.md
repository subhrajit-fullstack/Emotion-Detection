# 😊 Emotion Detection System

A Deep Learning based **Emotion Detection System** that detects human emotions from facial expressions using **Computer Vision and Convolutional Neural Networks (CNN)**.

The project can detect emotions from images as well as from a real-time webcam feed.

---

## 🚀 Features

- 😊 Facial emotion detection
- 📷 Emotion prediction from images
- 🎥 Real-time emotion detection using webcam
- 👤 Face detection using Haar Cascade
- 🧠 CNN-based deep learning model
- 📊 Dataset preprocessing and training
- 🔤 Multiple emotion classes

---

## 🛠️ Technologies Used

- **Python**
- **TensorFlow / Keras**
- **OpenCV**
- **NumPy**
- **Pandas**
- **Matplotlib**
- **Jupyter Notebook**
- **CNN (Convolutional Neural Network)**
